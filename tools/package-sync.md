# 공식 패키지 공지 연동

`pkg.html`은 사이트 공통 UI와 테마를 사용하고 검토한 로컬 JSON을 읽습니다.

## 갱신

```sh
python tools/sync-packages.py
python tools/sync-packages.py --full
python -m unittest discover -s tools -p 'test_packages.py'
node tools/test-packages.cjs
```

Python 표준 라이브러리만 사용합니다. 기존 GitHub 워크플로는 한국 시간 매일 08:30에 실행되며 일요일에는 전체 목록을 다시 확인합니다. 수집·검증 실패 시 기존 데이터를 유지합니다.

## 데이터와 계산

- 패키지 관련 공지는 원문 링크와 함께 보관합니다. 취소선으로 삭제된 내용은 추출에서 제외합니다.
- 이름과 실제 판매 기간이 확인되면 판매 날짜를 기록합니다. 이미지에서 확인한 기록은 `data/pkg-reviewed.json`에 근거와 함께 보관합니다.
- 판매 안내는 확인되지만 실제 기간이 없으면 공지일을 기준으로 회차를 구분합니다. 실제 시작일·종료일은 빈 값이고 화면에 판매일 미확정을 표시합니다.
- 같은 드래곤의 연속 공지가 3개월 미만 간격이면 합칩니다. 3개월 이상이면 별도 회차입니다. 월말은 달력의 마지막 날로 보정합니다.
- 같은 회차에서는 확인한 실제 판매 날짜를 우선합니다. 관련 근거 공지는 모두 유지합니다.
- 판매 종료, 결제 장애, 보상, 상시 일일/초보자/스타터 상품 변경은 새 판매로 계산하지 않습니다.
- 골드 드래곤, 헬 드래곤, 수룡, 히드라곤, 청룡, 백룡, 흑룡은 추출과 화면에서 제외합니다.
- 이미 시작된 회차 사이의 간격 중앙값으로 예상 복각일을 계산합니다. 미확정 기간은 공지일을 사용하고 그 사실을 표시합니다. 미래 공식 일정은 별도로 표시합니다.
- 마지막 기준일 이후 30개월간 재판매가 없거나 한 회차만 확인되면 예상일을 산정하지 않습니다. 지난 예상일을 미래로 계속 연장하지 않습니다.
- 기본 정렬은 예상 복각일이 빠른 순서이며 산정 불가 항목은 뒤에 표시합니다. 오늘 날짜는 한국 시간 기준입니다.
